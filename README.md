# Steam Store Clone (HTML5, CSS3 & JavaScript)

Clon interactivo y completo de la tienda digital de videojuegos **Steam**, listo para ejecutarse localmente o publicarse directamente en **GitHub Pages**.

## Estructura del Proyecto

```text
├── index.html          # Página principal (punto de entrada para GitHub Pages)
├── css/
│   └── styles.css      # Estilos visuales inspirados en la interfaz oficial de Steam
├── js/
│   └── app.js          # Lógica completa: catálogo, arte procedural, carrito, pagos, biblioteca y comunidad
├── assets/
│   └── .gitkeep        # Carpeta de recursos lista para GitHub (evita error de carpeta vacía)
└── README.md           # Documentación del proyecto
```

## Cómo subir y activar en GitHub Pages sin errores

1. Crea un repositorio nuevo en GitHub (por ejemplo: `tienda-steam`).
2. Sube **todos los archivos y carpetas** manteniendo `index.html` en la raíz del repositorio (no dentro de una subcarpeta extra).
3. Ve a **Settings → Pages** en tu repositorio.
4. En **Build and deployment → Source**, selecciona `Deploy from a branch`.
5. En **Branch**, elige `main` y selecciona la carpeta **`/ (root)`**, luego haz clic en **Save**.
6. En 1–2 minutos tu tienda estará en línea en `https://TU-USUARIO.github.io/tienda-steam/`.
